Your path · Module 1

Start big

Pick a goal you actually want, then break it down.

Don't start with variables. Start with something you want to exist: a game, a drawing, a calculator. The goal is what keeps you going when it gets hard.

Then break it down. A game is a window, a thing that moves, a thing you control, a score. Each piece is small enough to try today.

Try this: write one sentence about what you want to make. Underneath, list the three smallest pieces it needs.
