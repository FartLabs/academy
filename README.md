# FartLabs Academy

A self-taught path into software engineering, for anyone 12 and up. Live at
<https://academy.fartlabs.org>.

A static site styled with [Fart.css](https://css.fart.tools). No build step:
edit the HTML and `style.css` directly and open `index.html`, or serve the
folder (`python -m http.server`).

- `/` start here · `/path/` beginner modules and upcoming tracks · `/story/` ·
  `/llms/` · `/club/` · `/resources/`
- Each lesson is a short note in Ethan's words with cited link-outs at the
  bottom.

Deployed by `.github/workflows/pages.yml` on every push to `main`.
